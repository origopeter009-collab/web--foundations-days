About QuickNotes

QuickNotes is a simple app for writing down ideas, reminders and to-dos the moment they come to mind. It keeps your notes in one place so you can find and update them whenever you need to.

How to use QuickNotes

  1. Open the Home page and click in the note box.
  2. Type your note.
  3. Save it so you can find it later.
  4. Come back any time to read, edit or delete your notes.

Features

  • Fast note capture
  • Simple, clean layout
  • Works in any modern browser
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
Ctrl + D Delete note
